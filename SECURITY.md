# Security Policy

## Supported Versions

We release patches for security vulnerabilities. Only the latest version on the `main` branch is supported.

## Reporting a Vulnerability

If you discover a security vulnerability within `frontend-inspo-mcp` (e.g., a vulnerability in how we parse external UI registries or handle base64 decoding), please do not open a public issue.

Instead, please use GitHub's Private Vulnerability Reporting feature:
1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Provide a detailed description of the issue and a proof of concept if possible.

We will review your report and respond within 48 hours. We appreciate your help in keeping the ecosystem safe!

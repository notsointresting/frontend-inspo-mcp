The Machine Transformation

What this brings to your machine

Without this MCP, even the smartest models hallucinate outdated CSS classes, imagine unsupported animation props, and build brittle UI from memory. Here is how your agent behaves when grounded in reality:

❌ Without frontend-inspo-mcp Hallucinating
  • ✕ Guessed CSS & Tailwind: Generates non-existent Tailwind utility classes and awkward keyframe animations that break on reload.
  • ✕ Broken ARIA Semantics: Implements custom tabs and modals without keyboard bindings, failing WCAG compliance.
  • ✕ Generic 2021 Aesthetics: Defaults to bland blue gradient cards with inconsistent paddings and discordant color palettes.
  • ✕ Silent 3D/Shader Failures: Writes Three.js code that fails due to outdated matrix methods or broken GLSL vertex shaders.
✓ With frontend-inspo-mcp Grounded In Real Source
  • ✓ Exact TSX & CSS Source: Fetches verified code directly from shadcn, Magic UI, Aceternity, and Uiverse with 100% correct imports.
  • ✓ W3C Authoring Standards: Uses canonical W3C ARIA implementations (keyboard focus loops, Home/End keys, tabindexes).
  • ✓ Systematic Color Harmony: Employs Radix 12-step color scales and real-world brand token systems extracted via Refero.
  • ✓ Safe Security Boundary: Every payload is wrapped in untrusted data delimiters to prevent prompt injection from third-party code.

⚡ Zero Overhead Stdio

Runs as a lightweight subprocess on your machine. No background HTTP ports opened, zero cloud dependencies, and fast sub-millisecond local queries.

🛡️ Memory & Disk Caching

Polite HTTPS client with automated 10-minute in-memory caching and optional persistent disk cache via FRONTEND_INSPO_CACHE_DIR.

📜 Clean Licensing

Every resource carries its upstream license (MIT, Apache-2.0, OFL-1.1), author attribution, and origin repository links.

Interactive Tool Inspector

What your agent can call

Six read-only tools designed specifically for AI agent context windows. Inspect live requests and trimmed server replies captured directly from the built server.

asSandbox: true (get_code)

Generates self-contained, standalone runnable HTML previews with Tailwind CSS, Lucide icons, and Babel React runtime directly inside returned code.

inspo://{source}/{+id}

Direct Resource URI Template. Read any component as metadata and code parts natively inside Claude Desktop or Cursor.

find_component

A guided workflow prompt that transitions from natural language query to multi-source ranking to clean adapted code.

design_system_from_site

A prompt that transforms real-world URL tokens into a full DESIGN.md specification and Tailwind configuration.
